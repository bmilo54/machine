Guidance

Create a cloud computer, then give it to one user.

  1. Turn on the regions you use.

    Tick each region on the Regions page and save. The dashboard loads its office networks and the desktop types Alibaba sells there. Each region also has its own recording policy. The region page sets the shared website list, such as blocking youtube.com. Open a computer and choose Websites when that computer needs a different list. After a website list is in use, open that computer and choose Lock Secure DNS so Chrome and Edge cannot walk around it. You can use several regions at the same time.

    Open Regions
  2. Create the person on this dashboard.

    Each computer belongs to one user. Add a user creates the dashboard account and the Wuying login together. You do not use the admin site. If the Wuying password box is empty, the dashboard makes one and shows it on the Users page. Edit and delete are on that same page.

    Add a user
  3. Choose the hardware, if you want a size other than the standard computer.

    A profile belongs to one office network and sets the desktop type and the disks. Only the types sold in that office network are listed. It does not set internet. Leave this out when you create the computer to buy 4 vCPU, 8 GB, an 80 GiB system disk, and no data disk. Data disk 0 means no extra disk.

    Add a VM profile
  4. Set the internet once for each office network.

    Each office network has one premium plan shared by every computer in it. A computer cannot have its own peak. No premium leaves those computers without internet. Pay by bandwidth charges the peak for every hour the plan exists, including while the computers are off. Choosing no premium on that page removes the plan.

    Open Network
  5. Buy the computer.

    Pick the office network first. The user field can stay empty. Alibaba creates a Windows 11 Pro computer in that office network and bills it pay-as-you-go. New computers use the region's recording policy and its shared website list. Choose Websites on the computer when it needs its own list. The status stays Creating until the computer is ready.

    Create a cloud computer
  6. Wait until the status is Running.

    The desktop page updates itself. You can assign a user only after the computer is Running. If it is Stopped, start it first.

    Open the desktop list
  7. Lock Secure DNS on each computer that uses a website list.

    A blacklist or whitelist stops the computer from finding blocked sites. Chrome and Edge can look up sites on their own with Secure DNS and walk around that list. Open the computer while it is Running, choose Lock Secure DNS, then close Chrome and Edge once and open them again. Do this once on every computer. After that, workers cannot turn Secure DNS back on unless they are administrators on that computer.

    Open the desktop list
  8. Assign the computer after it exists.

    Open the desktop, choose Edit, and pick the user. Save. Alibaba replaces the assigned person, so one computer still has one user. They see the computer after they sign in.

    Choose a desktop, then Edit
  9. Let the person open the computer from this dashboard.

    The person signs in to this dashboard with their dashboard username and password, not the Wuying ones. They see My computer, can turn it on, and open it full screen in the browser. The page does not show Alibaba or Wuying, so they do not need the Wuying app or the details below.

  10. Or send the Wuying sign-in details.

    In the Wuying app, choose Enterprise & Business, enter the office network ID of the person's computer, then the username and password from the Users page. On the desktop list, the clipboard button copies this text for one user with the right office network ID.

  11. Screen recording reaches this dashboard after the person leaves and the computer stays running.

    Wuying records the whole session and shows the person a notice. A short piece stays on the computer until they close the Wuying window. That close leaves the computer Running, and the video uploads to the Alibaba console. Keep it Running for a few minutes so the upload can finish. Stopping or shutting down ends the upload, and that video does not arrive. Open Recordings after the upload. The page reads the same videos as the console. Play watches the video here. Download saves the file. The video list has its own time range. On the work report, choose the start and end dates and click Show. Write the work report then reads only the recordings in that range and writes what each person did. The report stays after the video is deleted. Videos are kept for about 15 days.

    Open recordings

Move a computer to another region

A computer stays in the region where it was bought. To take one from Hangzhou to Singapore, including the files already on its disks, make a new computer in Singapore from an image. The same steps work between any two regions.

  1. In the Alibaba console, open the computer in its current region and create a custom image. Set the image scope to the system disk and the data disk, so the data disk is included. Leave the computer running while the image is created.
  2. Turn off cleaning leftover personal user data before you create the image. That option is on by default. While it is on, the image leaves out the person's own files. Installed applications stay either way.
  3. Copy the image to the destination region, for example from Hangzhou to Singapore. The copy takes a while. The time depends on how much data is on the disks.
  4. Buy a new computer in that region from the copied image. Its disks must be at least as large as the disks in the image. Choose that region's office network and assign the same user. On this dashboard, turn that region on first if it is not already in use.
  5. The new computer has its own number and uses the destination region's recording policy. The original computer remains and keeps billing until you delete it. Check the files on the new computer first.
