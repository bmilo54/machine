Guidance

Create a cloud computer, then give it to one user.

  1. Create the person on this dashboard.

    Each computer belongs to one user. Add a user creates the dashboard account and the Wuying login together. You do not use the admin site. If the Wuying password box is empty, the dashboard makes one and shows it on the Users page. Edit and delete are on that same page.

    Add a user
  2. Choose the hardware, if you want a size other than the standard computer.

    A profile sets the desktop type and the disks. It does not set internet. Leave this out when you create the computer to buy 4 vCPU, 8 GB, an 80 GiB system disk, and no data disk. Data disk 0 means no extra disk.

    Add a VM profile
  3. Set the internet once for the whole office.

    Network is one premium plan shared by every computer in Singapore. A computer cannot have its own peak. No premium leaves every computer without internet. Pay by bandwidth charges the peak for every hour the plan exists, including while the computers are off. Choosing no premium on that page removes the plan.

    Open Network
  4. Buy the computer.

    The user field can stay empty. Alibaba still creates a Windows 11 Pro computer in Singapore and bills it pay-as-you-go. New computers use the screen-recording policy {{ recording_policy_name }}. The status stays Creating until the computer is ready.

    Create a cloud computer
  5. Wait until the status is Running.

    The desktop page updates itself. You can assign a user only after the computer is Running. If it is Stopped, start it first.

    Open the desktop list
  6. Assign the computer after it exists.

    Open the desktop, choose Edit, and pick the user. Save. Alibaba replaces the assigned person, so one computer still has one user. They see the computer after they sign in.

    Choose a desktop, then Edit
  7. Send the sign-in details.

    In the Wuying app, choose Enterprise & Business, enter the office network ID, then the username and password from the Users page. On the desktop list, the clipboard button copies this text for one user.

    Download the Wuying app Open the browser client

    Office network ID: {{ office_network_id|default:"Set DIRECTORY_ID in local settings" }}

  8. Screen recording reaches this dashboard after the person leaves and the computer stays running.

    Wuying records the whole session and shows the person a notice. A short piece stays on the computer until they close the Wuying window. That close leaves the computer Running, and the video uploads to the Alibaba console. Keep it Running for a few minutes so the upload can finish. Stopping or shutting down ends the upload, and that video does not arrive. Open Recordings after the upload. The page reads the same videos as the console. Play watches the video here. Download saves the file. Videos are kept for about 15 days.

    Open recordings
